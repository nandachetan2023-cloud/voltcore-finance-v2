# Suggested Submodules by Module

> Excludes HRMS and Organisation (already complete).
> Each section lists what currently exists, then what to add.

---

## Procurement

**Currently:** Purchase Orders, Expenses

| Submodule | Purpose |
|---|---|
| Vendors / Suppliers | Vendor master — contact info, payment terms, ratings, blacklist status |
| Quotations (RFQ) | Request for Quotation workflow — send RFQ, compare quotes, approve |
| Goods Receipt (GRN) | Record goods received against a PO, flag discrepancies |
| Purchase Returns | Return items to vendor, track credit notes |
| Contracts | Vendor contracts with start/end dates, renewal alerts |
| Approval Workflows | Multi-level PO approval chains by amount threshold |

## Finance

**Currently:** Dashboard, Ledger, Accounts Payable, Accounts Receivable, Journal Entries, Bank & Cash, Taxation, Budget, Financial Reports

| Submodule | Purpose |
|---|---|
| Invoices | Customer invoice generation, status tracking (draft → sent → paid) |
| Credit & Debit Notes | Issue/receive credit or debit notes against invoices |
| Fixed Assets Register | Track company assets, depreciation schedules, disposal |
| Cost Centres | Allocate expenses and revenue to departments or projects |
| Recurring Entries | Automate monthly/quarterly journal entries (rent, subscriptions) |
| Audit Trail | Immutable log of all financial transactions with user stamps |
